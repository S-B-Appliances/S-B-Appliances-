S&B APPLIANCES — GITHUB WEBSITE FILES

IMPORTANT: Upload ALL files in this folder directly into the ROOT of your GitHub repository (the same level as index.html).
Do not put these files inside the assets folder. The image paths in index.html are set up for the repository root.

FILES TO UPLOAD:
- index.html
- styles.css
- script.js
- sb-logo.jpeg
- sb-buying-flyer.jpeg
- bike-for-sale-1.jpeg
- bike-sold-white-red.jpeg
- bike-sold-blue-orange.jpeg

BIKE STATUS:
- bike-for-sale-1.jpeg = grey/black bike, AVAILABLE
- bike-sold-white-red.jpeg = white/red bike, SOLD
- bike-sold-blue-orange.jpeg = blue/orange bike, SOLD

The site uses the actual images supplied in the chat. The HTML image filenames exactly match the files included here.

PUBLISH:
GitHub repository → Settings → Pages → Deploy from a branch → main → /(root) → Save.
Wait a few minutes, then refresh the published website.

ENQUIRY FORM:
The form is configured for FormSubmit to send enquiries to the email address set in index.html.
The first time, FormSubmit may send a confirmation email to activate delivery. Test with a small photo first.
